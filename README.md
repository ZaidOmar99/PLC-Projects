# PLC Projects

This repository contains a collection of ladder logic projects developed using PLC simulation software (LogixPro). These projects demonstrate real-world industrial automation concepts such as sequencing, interlocks, timers, and counters.

Each project is organized in its own folder and includes ladder logic files, screenshots, and documentation where applicable.

## 📂 Projects Included

- [Water Tank Control System](./Water-Tank-Control-System)  
  Simulates automatic tank filling and draining using level sensors, pumps, and interlocks. Demonstrates sequential logic and safety constraints.

- [Traffic Light Control System](./Traffic-light)  
  Implements a timer-based state machine for managing intersection traffic lights with proper light sequencing and delays.

- [Garage Door Opener](./Garage-Door-Opener)  
  Models motor control with limit switches, safety interlocks, and manual override buttons. Demonstrates motor direction logic and event handling.

## 🛠️ Tools Used

- LogixPro PLC Simulator

## 💡 Purpose

These projects showcase foundational concepts in industrial control systems, including:
- Ladder logic programming
- Sequential process control
- Input/output interlocking
- Timer and counter usage
- Communication between PLCs and Modbus devices
